# DNAScale — sequence & trace workbench

A single-page web app that replaces the day-to-day Sanger workflow of **BioEdit** (alignment editor) and **Chromas / ChromasPro** (chromatogram viewer).
No install, no server, no network: open `index.html`, or drop `.ab1` files on it.

## Try it
- Open `index.html` in a browser → **Try the demo**, or drop the files in `samples/` onto the window
  (`Clone12_T7_fwd.ab1`, `Clone12_pRev.ab1`, `GENE1_reference.fasta`). These are *synthetic* traces with one SNP (col 330) and one heterozygous position (col 410).
- `?demo` on the URL loads the demo directly.
- `⌘K` opens the command palette, `?` lists shortcuts.

## Contig assembly
**Align or assemble…** has three modes: map reads to a reference (scaffold), assemble reads into contigs (no reference), or a plain multiple alignment.
- Overlaps are found with a k-mer index on both strands, verified by end-free alignment, then merged greedily into contigs; reverse reads are flipped (trace included).
- The consensus is quality-weighted (Phred) and mixed/heterozygous peaks count for both bases, so ambiguities get IUPAC codes (R, Y, M …) and are outlined in the consensus row.
- A coverage track replaces the conservation bars. Each contig is listed in the sidebar; unassembled reads stay in their own group.
- Consensus editing: pick any column, then set the call (A C G T, IUPAC, gap) in the inspector, or reset to automatic. Manual calls are marked and reset if columns move.
- Consensus goes into the PDF report and can be saved as FASTA or copied.

## Visualize (tab 5)
- **Helix 3D:** a rotating, draggable model of any sequence or read as A-, B- or Z-DNA (idealised parametric geometry). Colour by base, strand, Phred quality, or differences; differences pulse in the helix; click a base pair to select it in the alignment; "Follow cursor" keeps the helix centred on the alignment cursor; side, top-down and groove views; PNG and coarse-grained PDB export.
- **Dot plot**, **DNA walks** (2D walk, purine/pyrimidine, GC and AT skew), **chaos-game / k-mer maps** and **sequence logos**.
- Inspired by DNAvisualization.org (Apache-2.0; Lee et al. 2019) and public helix models; implemented from the published methods, with no code copied.

## Analysis tools
- **Find** (`⌘F`): exact or IUPAC search, or similarity search by local alignment; both strands; matches are highlighted in the alignment.
- **Analysis view** (`4`): six-frame ORF map with one-click translation, G+C frame plot, restriction map with fragment table (linear or circular), non-cutters, hydropathy / hydrophilicity / antigenicity profiles, reverse translation to degenerate DNA with a degeneracy plot. These can be added to the PDF report.
- **Formats in:** ABIF, SCF, ZTR (raw/RLE/zlib/delta/16-to-8/follow; not the Chebyshev or XRLE variants), 454 SFF, GCG RSF, FASTA, FASTQ, GenBank, GenPept, EMBL, SwissProt, Clustal. **Out:** FASTA, FASTQ (reads with quality), Clustal, PDF and more.
- **Copy chromatogram** (or alignment view) as an image for slides and documents.

## What it does
| Old tool | DNAScale |
|---|---|
| Chromas: open `.ab1`, view peaks, Phred quality, trim, edit calls, reverse-complement | Trace dock under the alignment, auto-trim (Mott), mixed-peak flags, base editing, flip |
| BioEdit: alignment grid, colour schemes, consensus, translate, ORFs, restriction map | Canvas alignment (thousands of columns), 7 colour schemes, consensus + conservation, translation track, ORF finder, restriction enzymes |
| BioEdit → ClustalW / PHYLIP / BLAST shells | Built-in profile aligner (Gotoh, affine gaps), progressive MSA, NJ tree, identity matrix |
| Formats | in: `.ab1/.abi/.scf`, FASTA, GenBank, Clustal, `.dnascale`; out: FASTA, Clustal, Newick, CSV, PNG, SVG, **PDF lab report**, `.dnascale` |

Formats read: ABIF (`.ab1`) and SCF v2/v3 (`.scf`), parsed from the publicly documented format layouts. Reads without Phred scores get an estimated quality.

## Layout
```
index.html          app shell
css/style.css       design tokens (light/dark) + components
js/data.js          genetic codes, BLOSUM62, restriction enzymes
js/core.js          parsers (ABIF, SCF, FASTA, GenBank, Clustal), aligner, ORF/restriction/NJ
js/trace.js         chromatogram renderer
js/pdf.js           vector PDF writer (own code, ported from LabScale)
js/report.js        lab report: summary, differences, alignment, chromatogram evidence
js/legal.js         imprint, privacy, licences (shown from the footer links)
js/alignview.js     virtualised canvas alignment viewer
js/app.js           state, panels, editing, dialogs, import/export
js/demo.js          synthetic Sanger data generator
samples/            demo files — synthetic, generated by js/demo.js (not real sequencing data)
```

## Not (yet) replicated
In-app BLAST (NCBI's API blocks browser requests; DNAScale opens the NCBI form pre-filled instead), PHYLIP maximum-likelihood/parsimony, RNA structure, sound output.

## Provenance & licensing
Written from scratch; no code, binaries, icons, sounds or help text from BioEdit or Chromas are included, and nothing was decompiled.
- Algorithms are published methods: Gotoh affine-gap alignment, UPGMA guide tree, neighbour-joining (Saitou & Nei), Mott quality trimming, Jukes–Cantor distance.
- File formats follow the public ABIF and SCF specifications.
- Data: NCBI genetic-code tables and the BLOSUM62 matrix (Henikoff & Henikoff 1992) are public scientific data; restriction-enzyme recognition sites are factual and were compiled by hand (not copied from REBASE or BioEdit files).
- "BioEdit" and "Chromas" are named only to describe the workflow replaced. Check the name "DNAScale" for trademark conflicts before publishing, and choose a licence (e.g. MIT) for this code.

## Format notes
`.ab1` and SCF v3 writers were checked against Biopython (ABIF) and by round-trip; the SFF reader against files written by Biopython. ZTR is implemented from the public specification and verified only on self-made files — please test with real ZTR files.
